# KLSCM ABSA Aspect Ontology V1

Status: frozen initial ontology, 2026-08-19. Machine-readable authority: `data/processed/absa_v1/absa_aspect_ontology_v1.json`.

This controlled ontology contains 20 aspect families. It was derived from the frozen 32-topic c1 taxonomy and the historical ABSA/relevance concepts, but topics are contextual themes rather than aspect labels. ABSA is mention-level and extracts only evaluated targets. Factual references create no mention; `neutral` remains in the controlled schema for genuinely evaluative, explicitly non-polar assessments, not mere facts.

The families are: `route_course`, `weather_conditions`, `organization_operations`, `registration_entry`, `race_pack_expo`, `transport_access`, `crowd_community_atmosphere`, `volunteer_support`, `aid_stations_hydration`, `facilities`, `safety_medical`, `event_information`, `training_preparation_pacing`, `photography_media`, `race_performance`, `physical_experience`, `emotional_experience`, `value_cost`, `finisher_items`, and `emerging_other`.

Definitions, inclusion examples, boundaries, related aspects, and topic links are maintained in the JSON artifact to prevent the prose and executable vocabulary from diverging.
